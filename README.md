# NutriAdapt — Адаптивное веб-приложение для управления весом и питанием (6–50 лет)

Статическое веб-приложение на чистом **HTML5 / CSS3 / ES-модулях JavaScript** без сборщиков и серверной части, полностью готовое к публикации на **GitHub Pages**.

---

## Ключевые возможности

1. **Возрастная дифференциация формул (6–50 лет):**
   - **6–10 лет:** педиатрические уравнения ВОЗ/FAO/UNU (`22.7 × вес + 495` для мальчиков и `22.5 × вес + 499` для девочек).
   - **10–18 лет:** педиатрические уравнения для подростков (`17.5 × вес + 651` для юношей и `12.2 × вес + 746` для девушек).
   - **18–50 лет:** формула Миффлина — Сан Жеора (`10 × вес + 6.25 × рост − 5 × возраст + 5` для мужчин и `− 161` для женщин).
   - Контроль безопасного дефицита (предупреждение при превышении 15% у детей и подростков) и обязательный медицинский дисклеймер.

2. **Адаптивная программа снижения веса:**
   - Сравнивает средний вес за последние 7 дней со средним весом за предыдущие 7 дней.
   - Проверяет заполненность дневника питания (не меняет калорийность «вслепую», если пользователь не записывает еду).
   - При обнаружении плато или роста веса предлагает плавное снижение целевой калорийности на **5–8%** с записью в журнал адаптаций (`дата, причина, старая цель → новая цель`).

3. **Дневник питания и поиск продуктов:**
   - Неограниченное число строк приёмов пищи за день с указанием типа приёма (или своего названия), времени (`ЧЧ:ММ`), продукта, граммов и веса до еды.
   - Поиск продуктов через **Open Food Facts API**, резервный поиск **USDA FoodData Central** и офлайн-базу `data/foods-fallback.json`.

4. **Календарь на месяц:**
   - Индикация калорий и веса на каждый день месяца, быстрый переход к «Сегодня» и редактирование/удаление записей прямо из панели просмотра дня.

5. **Хранение в браузере (IndexedDB) + Экспорт/Импорт JSON:**
   - Все записи дневника, взвешиваний, профиля и журнала адаптаций хранятся в `IndexedDB`.
   - Кнопки **«Экспорт JSON»** и **«Импорт JSON»** в шапке позволяют переносить данные между телефоном и компьютером.

## Как запустить локально

Поскольку приложение использует ES-модули (`<script type="module">`), открывать `index.html` нужно через любой локальный HTTP-сервер (протокол `file://` блокирует `import` и `fetch` в браузерах по правилам CORS):

```bash
# Вариант 1: Python 3
python3 -m http.server 8080

# Вариант 2: Node.js (npx)
npx serve .
```

После этого откройте в браузере `http://localhost:8080`.

## Как опубликовать на GitHub Pages

1. Создайте новый репозиторий на GitHub и загрузите в его корень все файлы и папки проекта (`index.html`, `css/`, `js/`, `data/`, `README.md`).
2. Перейдите в **Settings → Pages** вашего репозитория.
3. В разделе **Build and deployment → Source** выберите `Deploy from a branch`.
4. Выберите ветку `main` (или `master`) и папку `/ (root)`, нажмите **Save**.
5. Через 1–2 минуты приложение будет доступно по адресу `https://<ваш-логин>.github.io/<имя-репозитория>/`.

---

## Как перенести данные между устройствами

1. На исходном устройстве нажмите кнопку **«Экспорт JSON»** в верхней панели — скачается файл `nutriadapt-backup-YYYY-MM-DD.json`.
2. Перешлите этот файл на другое устройство (или сохраните в облако).
3. На новом устройстве нажмите **«Импорт JSON»** и выберите сохранённый файл — профиль, история веса, дневник питания и журнал адаптаций мгновенно восстановятся.
